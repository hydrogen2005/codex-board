关于这些数字

本地日志 token 用量不等于订阅额度或账单金额。缺失日志、云端执行和未导入设备不会自动补齐。

同一事件出现在多台电脑时只计一次，归入「设备归属不明」。数据仅保留在当前页面内，关闭或刷新页面后需重新导入。
